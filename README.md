# 🛠️ Craftorium Decision Records (CDR)

Вітаємо в дзеркалі репозиторію **Craftorium**. Тут документуються всі ключові стратегічні, технічні та організаційні рішення щодо розвитку нашої екосистеми.

---

## 📌 Що таке СDR?

**СDR (Craftorium Decision Record)** — це короткий документ, який описує важливе стратегічне чи технічне рішення, його контекст та наслідки. 

Якщо ви бажаєте детальніше ознайомитися з концепцією СDR, перегляньте наші [переклади статтей та матеріалів](./translations/).

---

## 📂 Структура репозиторію

* [`сdrs/`](./adrs/) — Журнал усіх прийнятих та активних рішень.
* [`templates/`](./templates/) — Шаблони для створення нових ADR.
* [`translations/`](./translations/) — Навчальні матеріали та переклади українською мовою.

---

## 🚀 Як запропонувати новий СDR?

1. Ознайомтеся з [CONTRIBUTING.md](./CONTRIBUTING.md).
2. Скопіюйте [шаблон ADR](./templates/adr-template-short.md).
3. Створіть новий branch у форматі `cdr/номер-короткий-опис`.
4. Оформить PR та залучіть спільноту Craftorium до обговорення.
