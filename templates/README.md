# Рішення

Для нових записів рішень Craftorium (CDR), будь ласка, використовуйте один із наведених нижче шаблонів як початкову точку:

- [cdr-template.md](cdr-template.md) містить усі розділи з поясненнями до них.
- [cdr-template-bare.md](cdr-template-bare.md) містить усі розділи порожніми (без пояснень).

---

> **Примітка:** За основу було взято [шаблон MADR](https://github.com/adr/madr/tree/develop/template).
